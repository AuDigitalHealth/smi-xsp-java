# Security

## Reporting a vulnerability

Report security vulnerabilities to: **admin.opensource@digitalhealth.gov.au**

Do not open a public GitHub issue for security vulnerabilities.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 17.0.0 | Yes       |
| 11.0.0 | Yes       |
| 8.0.0 | Yes       |
